# Flexible Packaging Guides

This repository provides public buying guides for custom flexible packaging buyers.

The guides are prepared by Huasheng Packaging to help buyers understand packaging types, material structures, printing options, MOQ, samples and quotation preparation.

Official website: https://gdhspack.com
